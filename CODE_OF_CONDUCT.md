# Code of Conduct

## Our standard

Everyone participating in the physdraw project — issues, discussions, code
review — is expected to be respectful, patient, and constructive. We are here
to build good tools; critique code and ideas, never people.

## Expected behavior

- Be kind and assume good intent.
- Give and receive feedback gracefully.
- Keep discussions focused on the project.
- Respect differing viewpoints and levels of experience.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Trolling, insulting, or demeaning commentary.
- Publishing others' private information without consent.
- Sustained disruption of community discussions.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, and account
participation that violate this Code of Conduct. Repeated or severe violations
result in a permanent ban.

Report issues to the maintainers via GitHub by opening an issue marked
`conduct` or contacting a maintainer directly. All reports will be reviewed
and handled with discretion.

This project adapts the spirit of the [Contributor Covenant][cc].
